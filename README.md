# Landing Page — KendryaIA

Landing page institucional da KendryaIA: sistema de etiquetas inteligentes para restaurantes com reconhecimento de voz e IA (n8n + OpenAI), com impressão direta por Bluetooth.

## Stack

- Vite 8 + React 19
- CSS Modules

## Rodando local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

O projeto é uma SPA estática (Vite). Pode ser publicada na Vercel, Netlify, GitHub Pages ou qualquer servidor estático.
